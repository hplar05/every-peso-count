# Every Peso Counts - Usability Checklist

Thank you for helping us test the **Every Peso Counts** transparency portal for Barangay Bella Luz. Please go through the following scenarios and note down any issues, confusion, or feedback you encounter.

## 1. Public Portal (Resident View)

**Tasks:**
- [ ] Visit the homepage (`everypesocount.online`).
- [ ] Navigate to the **Projects** page. Are the budgets clear?
- [ ] Navigate to the **Citizens Feedback Hub**.
- [ ] Submit a new test feedback ticket (try submitting one with profanity to ensure it's blocked).
- [ ] Note down the 8-character tracking code.
- [ ] Check the status of your ticket using the tracking code.
- [ ] View the **Public Feedback Board**.

**Feedback / Notes:**
- *Did you encounter any confusing language?*
- *Was it easy to find where to submit your feedback?*
- *Did the site load quickly on your mobile phone?*

---

## 2. Admin & Staff Portal (Official View)

**Tasks:**
- [ ] Log in as a **Kagawad**. Verify that you only see the Feedback and Announcements sidebar options.
- [ ] Log in as an **Admin / Secretary**.
- [ ] Go to the **Admin Dashboard** and review the summary cards.
- [ ] Navigate to **Analytics**. Are the charts rendering correctly? Do they make sense?
- [ ] Go to **Projects**. Try updating the status of an active project to 'Completed'.
- [ ] Go to **Feedback Inbox**. Find the ticket you submitted in Step 1.
- [ ] Submit an "Official Response" and set the status to 'Resolved'.
- [ ] Navigate to **Sessions & Attendance**.
- [ ] Click on a scheduled session and test uploading a dummy "Minutes of Meeting" PDF document.
- [ ] Go to **Staff Directory** and view a Kagawad's QR Code.

**Feedback / Notes:**
- *Were there any errors when uploading the PDF?*
- *Is the dashboard layout intuitive?*
- *Are there any missing data fields you expected to see when viewing a project or session?*
